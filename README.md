# Charm the Commuter: Forecast a City That Isn't

A one-line weather forecast for Drizzlewick, a city that does not exist, written to make a bored commuter smile at a rainy bus stop: rain until noon, then more rain, then a brief sunny spell the locals call Tuesday — and the 8:15 bus is late, so bring two umbrellas. Running `node main.ts` writes the 139-character forecast to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
